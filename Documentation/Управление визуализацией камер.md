# Управление визуализацией камер в TurtleBot3 GUI

## Обзор

В рамках выполнения задачи 6 реализовано управление визуализацией работы системы технического зрения и триггерное управление выводом текстовой информации на изображения с камер.

## Новые возможности

### 1. Режимы визуализации

Реализованы три режима визуализации для каждой камеры:

- **Режим 0**: Исходное изображение (без обработки)
- **Режим 1**: Бинаризованное изображение (черно-белое)
- **Режим 2**: Изображение с детектированными линиями разметки (зеленые контуры)

### 2. Триггерное управление текстовым оверлеем

Добавлена возможность включать и отключать вывод текстовой информации поверх изображений с камер.

## Использование

### Управление режимами визуализации

1. В главном окне GUI перейдите на вкладку "Control Panel"
2. Найдите группу "Camera Visualization Control"
3. В полях "Lane Camera Mode" и "Top Camera Mode" введите номер режима (0, 1 или 2)
4. Нажмите кнопку "Apply Visualization Modes" для применения изменений

### Управление текстовым оверлеем

1. В группе "Camera Visualization Control" введите текст в поле "Text Overlay"
2. Нажмите переключатель "Toggle Text Overlay" для включения/отключения вывода текста
3. Текст будет отображаться в верхнем левом углу изображений с обеих камер

## Техническая реализация

### Топики ROS

Для управления визуализацией используются следующие топики:

- `/lane_camera/visualization_mode` (Int32) - режим визуализации для передней камеры
- `/top_camera/visualization_mode` (Int32) - режим визуализации для верхней камеры
- `/lane_camera/text_overlay` (String) - текстовый оверлей для передней камеры
- `/top_camera/text_overlay` (String) - текстовый оверлей для верхней камеры

### Модифицированные файлы

1. **camera_processor.py**:
   - Добавлена поддержка разных режимов обработки изображений
   - Реализована подписка на топики управления визуализацией
   - Добавлена возможность вывода текстовой информации поверх изображений

2. **turtlebot_gui.py**:
   - Добавлены элементы управления для визуализации (текстовые поля, кнопки)
   - Реализована логика публикации команд управления в соответствующие топики
   - Добавлена поддержка буферизации текстовых сообщений

3. **setup.py**:
   - Обновлен список скриптов для установки

## Примеры использования

### Переключение между режимами визуализации

```python
# Установить режим 1 (бинаризованное изображение) для передней камеры
lane_mode_pub.publish(1)

# Установить режим 2 (с линиями) для верхней камеры
top_mode_pub.publish(2)
```

### Включение текстового оверлея

```python
# Включить текстовый оверлей с сообщением
text_msg = String(data="Robot Status: OK\nMode: Manual")
lane_text_pub.publish(text_msg)
top_text_pub.publish(text_msg)
```

## Запуск системы

Для запуска системы с новыми возможностями используйте стандартный launch-файл:

```bash
roslaunch turtlebot3_gui turtlebot3_dual_cam.launch
```

## Отладка

Для отладки можно использовать стандартные инструменты ROS:

```bash
# Просмотр изображений с камер
rostopic echo /lane_camera/processed
rostopic echo /top_camera/processed

# Просмотр текущих режимов визуализации
rostopic echo /lane_camera/visualization_mode
rostopic echo /top_camera/visualization_mode

# Просмотр текстового оверлея
rostopic echo /lane_camera/text_overlay
rostopic echo /top_camera/text_overlay
```

## Ограничения

- Текстовый оверлей отображается в верхнем левом углу изображений
- Максимальная длина текста ограничена размером изображения
- Режимы визуализации применяются ко всем изображениям с соответствующей камеры
